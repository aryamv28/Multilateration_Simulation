Underlying mathematical model

dᵢ = √[(x−xᵢ)² + (y−yᵢ)²]dᵢ − d₁ = v(tᵢ − t₁)

The program searches for a point (x, y) where the predicted distance differences most closely match those calculated from the timestamps. Each distance-difference equation defines a hyperbola.

Important limitations

Each event must represent one identifiable sound pulse heard by all microphones using a common clock. The source must be nearly stationary during that pulse’s travel to the microphones. A continuous undifferentiated sound cannot be localized from arbitrary timestamps alone; the arrivals of each common event must be matched. Three microphones provide the two time-difference equations required for 2D estimation, but may produce multiple possible positions or sensitivity to noise. Restrict the search area and place the microphones in a non-collinear triangle. Motion playback is sampled tracking, not an automatic real-time hardware connection.
